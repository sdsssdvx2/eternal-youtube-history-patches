시청한 영상 표시

홈·Shorts·영상 상세/관련 영상·구독·채널·검색 결과·Watch Later·좋아요·재생목록·재생목록 상세·시청 기록·내 페이지는 각각 독립 설정을 가질 수 있습니다. YouTube 상단의 Eternal · 현재 페이지 버튼에서 그 페이지의 흐림/숨김을 동시에 켜거나 끄고, 두 진행률 기준을 같이 쓰거나 따로 지정할 수 있습니다. 두 조건을 모두 만족하면 숨김이 우선합니다. 여기의 값은 아직 개별 설정하지 않은 페이지의 기본값입니다. PC와 Android 설정은 서로 동기화하지 않습니다.

옅게 표시는 기본적으로 썸네일만 불투명도를 낮춥니다. ‘영상 정보도 함께’ 옵션을 켜면 카드 정보도 같은 불투명도로 연동됩니다. 흑백 옵션을 켠 경우에만 grayscale을 적용하며 CSS blur는 사용하지 않습니다. 0%는 Eternal 원장에 한 번이라도 기록된 영상을 대상으로 합니다.

나중에 볼 동영상 자동 정리

기본값은 자동 정리 꺼짐 / 60%입니다. 진행률을 모르는 영상은 절대 자동 제거하지 않습니다. 자동 정리를 켜면 재생 중 기준에 도달한 영상의 Watch Later 소속 여부를 확인해 제거하고, Watch Later 페이지를 열 때 D1과 동기화한 뒤 기준 이상 항목을 한 번 정리합니다.
