Eternal YouTube History 설정

시청한 영상 표시 · 공통 기본값

이 값은 공통 기본값입니다. 기존에 저장된 페이지별 설정은 그대로 보존됩니다. YouTube에서는 표시 / 흐림 / 숨김 빠른 버튼으로 현재 페이지의 표시 모드를 바꿀 수 있습니다.

흐림과 숨김이 모두 켜져 있으면 숨김이 우선합니다. 0%는 Eternal 원장에 한 번이라도 기록된 영상을 뜻합니다. PC와 Android 설정은 서로 동기화하지 않습니다.

나중에 볼 동영상 정리

수동 안전 정리 버튼은 나중에 볼 동영상 페이지에 표시됩니다. 자동 정리를 켜면 페이지 진입 시 같은 안전 경로를 확인창 없이 실행합니다. 전체 목록을 두 번 대조하고 journal을 먼저 저장한 뒤 각 항목을 다시 확인하며, 하나라도 모호하면 즉시 중단합니다. 마지막 정리는 되돌릴 수 있습니다.
