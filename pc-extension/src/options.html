Eternal YouTube History 설정

시청한 영상 표시

옅게 표시 모드는 기본적으로 썸네일만 불투명도를 낮춥니다. ‘영상 정보도 함께’ 옵션을 켜면 채널 이미지·제목·채널명·조회수·업로드 시점·메뉴까지 같은 불투명도로 연동됩니다. 흑백 옵션을 켠 경우에만 grayscale을 적용하며 CSS blur는 전혀 사용하지 않습니다. 0%는 Eternal 원장에 한 번이라도 기록된 영상을 대상으로 합니다. 1~100%는 실제 진행률을 알고 있는 영상만 기준 이상일 때 적용합니다.

Cloudflare D1 중앙 원장

D1이 본체이고 PC IndexedDB는 YouTube 카드 표시를 위한 로컬 캐시입니다. v0.7은 Chrome 시작 시 동기화, 15분 polling, 자동 History 탭 생성 같은 백그라운드 작업을 하지 않습니다. YouTube 페이지를 실제로 열거나 이동할 때만 필요한 변경분을 확인합니다.
